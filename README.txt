Dutch Quest — iPhone PWA package

This version is prepared for iPhone/Safari and Home Screen installation.

Files:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

Important:
iPhone cannot install a full PWA correctly from a local file. These files must be served over HTTPS.

Easiest deployment options:
1. GitHub Pages
2. Netlify Drop
3. Cloudflare Pages

After deployment:
1. Open the HTTPS link in Safari on iPhone.
2. Tap Share.
3. Tap Add to Home Screen.
4. Launch Dutch Quest from the Home Screen.

Offline mode becomes available after the first successful load.
Progress is stored locally on the device.
